インストール動画ガイド

セットアップの全体の流れを動画でご確認ください。約2分間でインストール完了までを説明します。

📹
注： 動画が見られない場合は、下記の「セットアップ」セクションで詳しい手順を確認してください。

セットアップ

最初の準備は一度だけです。ファイルを解凍してインストールプログラムを実行してください。

1
ファイルの解凍
ダウンロードした pawn-auto-printer.zip を右クリックし、「すべて展開」を選びます。
※解凍先はダウンロードフォルダのままでOKです。その場所で動作します。
2
インストールの実行
解凍したフォルダ内の install_all.bat を 右クリック → 「管理者として実行」 【自動設定】
必要なソフト（Python、SumatraPDF）とライブラリが自動的にインストールされます。
※アプリは解凍したフォルダ内で動作するため、別の場所へのコピーは不要です。
3
インストール完了の確認
黒い画面に 「Setup Complete!」 と表示されたらインストール成功です。
「何かキーを押すとこの画面を閉じます...」と表示されたら、キーボードのキーをどれか押して画面を閉じてください。
※その後、PCを再起動してください。再起動後、アプリが自動的に起動します。
💡
所要時間： 約2〜3分で完了します。黒い画面が表示されますので、完了するまでそのままお待ちください。
⚠️
重要： 解凍したフォルダは削除しないでください。このフォルダがアプリの本体です。
必要であれば、フォルダごと好きな場所（例：ドキュメント、デスクトップなど）に移動してから実行してください。

デスクトップにアイコンを追加する（任意）

アプリは自動で起動しますが、手動で開いたりログを確認したい時のために、デスクトップにアイコンを出しておくと便利です。

1
アプリのフォルダ内にある create_desktop_shortcut.bat をダブルクリックしてください。
2
完了
これだけでデスクトップに 「PDF Auto Printer」 のアイコンが作成されます。
💡
ポイント： このアイコンをダブルクリックすれば、いつでも設定画面（トレイアイコン）を表示・再起動できます。
フォルダを移動した場合は、もう一度 create_desktop_shortcut.bat を実行してアイコンを作り直してください ポイント： このアイコンをダブルクリックすれば、いつでも設定画面（トレイアイコン）を表示・再起動できます。

プリンターの選択

特定のプリンター（ラベル用、白黒専用など）を指定して印刷したい場合の設定です。

方法1：アプリのメニューから選ぶ（推奨）

アプリに直接プリンターを記憶させる、最も確実な方法です。

1
タスクトレイ（画面右下の時計の横）にある プリンターのアイコン（水色）を右クリックします。
※アイコンが見当たらない場合は、時計の横の「∧」マークの中を確認してください。
2
「Select Printer」 メニューを開きます。
3
一覧から使用したいプリンターを選んでクリックします。
メニューイメージ：
Select Printer ▶
✓ Default Printer
Brother HL-L5210DN
EPSON SC-P800
Quit
✅
記憶機能： 一度選択したプリンターは、次回以降も自動的に選ばれます。

方法2：Windowsの設定で「既定」にする

特定のプリンターを指定せず、Windowsの標準プリンターとして設定する方法です。

  1. 「設定」→「Bluetooth とデバイス」→「プリンターとスキャナー」を開きます。
  2. 使用したいプリンターを選び、「既定として設定」ボタンを押します。

使い方

アプリ稼働中に、対象のファイル名（PDFまたはHTML）をダウンロードフォルダに保存するだけで自動印刷が開始されます。

ファイル名に含む文字 印刷サイズ
PRINT_A4 A4サイズ（普通紙・請求書など）
PRINT_A5 A5サイズ（質札）
💡
アイコンが見当たらない場合：
タスクトレイの「∧」ボタン（隠れているインジケーターを表示）を押すと、中に入っていることがあります。
✨
スマート機能： 印刷が完了したファイルは、ダウンロードフォルダを散らかさないよう自動的に削除されます。

セキュリティ対策

Windowsのセキュリティ機能により、アプリの動作が制限される場合の対処法です。

「PCが保護されました」と表示される

「詳細情報」→「実行」の順にクリックしてください。このアプリは安全です。

動作がブロックされる場合

フォルダ内の unblock_files.bat を実行してください。すべてのプログラムを一括で許可状態にします。

⚠️
ノートン（Norton）などのセキュリティソフトをお使いの方へ
インストール中に「このプログラムは保護されていません」「疑わしいファイル」などの警告が表示されることがあります。

対処法：
1. 警告が表示されたら、「許可」「続行」などのボタンをクリックしてインストールを進めてください
2. ブロックされてインストールできない場合は、ノートンを一時的に無効化してからインストール実行、その後再度有効化してください
3. インストール完了後、フォルダ内の unblock_files.bat を実行して、すべてのプログラムを許可状態にしてください
💡
実行後も動作がブロックされる場合：
セキュリティソフトの「除外設定」「信頼できるソフトウェア」などに、このアプリのフォルダを追加してください。これにより、ソフトが正常に動作するようになります。

困ったときは

印刷が始まらない、アプリが見当たらないなどのトラブルの際のチェック項目です。

1
アイコンを探す

2
ログを確認する
フォルダ内の printer_log.txt を開くと、エラーの内容が記録されています。

アプリの更新方法

新しいバージョンのアプリ（auto_printer.py など）が届いた際の手順です。

1
stop_printer.bat を実行して、今のアプリを止めます。
2
新しいファイルを現在のフォルダに上書きコピーします。
3
デスクトップのショートカットから再起動してください。
💡
config.json は上書きせずにそのまま使うと、プリンター設定が維持されます。

付録：インストール・アンインストール

初期インストール（失敗した場合の手動導入）

自動セットアップが失敗する場合のみ、以下のツールを個別にインストールしてください。

1. Python
公式サイトからダウンロード。
※「Add Python to PATH」に必ずチェック
2. SumatraPDF
公式サイトからダウンロード。
※64-bit installer推奨

完全アンインストール（最初からやり直す場合）

インストール済みのパソコンから、すべての関連ファイルを削除する手順です。

1
アプリを停止
フォルダ内の stop_printer.bat または emergency_stop.bat を実行してください。
2
Windowsの「プログラムと機能」から削除
「設定」→「アプリ」→「アプリと機能」を開き、以下を検索して削除します：
  • Python を検索し、見つかったもの（Python 3.x、Python Launcher等）をすべて削除
    ※アンインストール時に「ユーザー設定も削除しますか？」と聞かれたら「はい」を選択
  • SumatraPDF
3
自動起動の設定を削除
Windowsキー + R を押し、shell:startup と入力してEnterを押します。
開いたフォルダ内に「PDF Auto Printer」のショートカットがあれば削除してください。
※これにより、次回起動時に自動起動されなくなります
4
アプリフォルダを削除
ダウンロードフォルダやデスクトップにある pawn-auto-printer フォルダを右クリックし、「削除」を選びます。
※config.json（プリンター設定）も一緒に削除されます
5
デスクトップショートカットを削除
デスクトップに作成された「PDF Auto Printer」アイコンがあれば右クリックし、削除します。
6
完了
これでパソコンがすっきりリセットされました。新しいバージョンの解凍ファイルをダウンロードして、もう一度 install_all.bat から始められます。
💡
Pythonが削除できない場合：
「コントロールパネル」→「プログラム」→「プログラムと機能」から削除してみてください。
⚠️
注意： Python を削除する際、他のアプリで Python を使っている場合があります。不安な場合は、Python を削除せず、アプリフォルダだけ削除して新バージョンを試してみてください。
