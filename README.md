# Pawn PDF自動印刷アプリ 手順書

このアプリは、Windowsの「ダウンロード」フォルダを監視し、特定のファイル（PDFまたはHTML）を検知すると自動的に印刷を行い、完了後にファイルを削除します。

## 0. 解凍（プログラムを取り出す）

ダウンロードしたファイルが「ジッパー付きのフォルダ（ZIP形式）」のままでは動きません。まず中身を取り出します。

1.  ダウンロードした **`pawn-auto-printer.zip`** を **「右クリック」** します。
2.  メニューから **「すべて展開...」** または **「展開」** を選びます。
3.  画面が出てきたら、そのまま **「展開」** ボタンを押します。
4.  新しく出てきた（青いジッパーが付いていない）フォルダを開いて、以下の手順に進んでください。
    *   ※ 取り出した後は、元の **`pawn-auto-printer.zip`** は削除しても大丈夫です。

## 1. セットアップ（一括実行）

1.  このフォルダ内の **`install_all.bat`** を「右クリック」して **「管理者として実行」** してください。
    *   ※文字化けエラー防止のため、画面内のメッセージは英語になっています。
2.  「Setup complete!」と表示されるまで待ち、何かキーを押して画面を閉じます。
3.  **重要**: 設定を反映させるため、**一度パソコンを再起動**してください。

---

## 2. 自動起動とアイコンの設定

再起動後、以下の設定を行うことでより便利に使用できます。

1.  **デスクトップアイコンの作成**:
    *   **`create_desktop_shortcut.bat`** をダブルクリックして実行します。
    *   デスクトップに「PDF Auto Printer」アイコンが作成されます。
    *   ※アプリが既に動いている時にこのアイコンを押すと「already running」と通知が出ます。アプリが止まっている時だけ再起動用として使います。

---

## 補足：プリンターの設定（重要）

このアプリは **「Windowsの通常使うプリンター（既定のプリンター）」** を使用して印刷します。白黒印刷用の **Brother 5210** などで印刷したい場合は、以下の設定を行ってください。

### Windows 11 での設定方法
1.  画面下の **「スタートボタン（田マーク）」** を押し、**「設定（歯車マーク）」** を開きます。
2.  左側のメニューから **「Bluetooth とデバイス」** を選び、**「プリンターとスキャナー」** をクリックします。
3.  一覧から **「Brother HL-L5210DN」**（またはお使いのBrotherプリンター名）を探してクリックします。
4.  右上の **「既定として設定」** ボタンを押します。
    *   ※もしボタンが表示されない場合は、一つ手前の画面で「Windows で通常使うプリンターを管理する」を **オフ** にしてから再度試してください。

---

## 3. 使い方

アプリが動いている状態で、ブラウザやSlack等から以下の名前でファイルをダウンロードしてください。
* **PRINT_A4.pdf** または **PRINT_A4.html** → **A4** で自動印刷
* **PRINT_A5.pdf** または **PRINT_A5.html** → **A5** で自動印刷

**💡 ポイント:**
* ファイル名に「PRINT_A4」または「PRINT_A5」という文字が含まれていれば反応します。
* **HTMLファイルの場合:** 自動的にPDFに変換された後で印刷されます（Edgeのバックグラウンド機能を使用します）。
* Windows等で自動的に **「PRINT_A4 (2).pdf」** のような名前になっても問題なく自動印刷されます。
* 印刷成功後、ダウンロードフォルダ内のファイルは**自動的に削除**されます。
* アプリはバックグラウンドで動くため、黒い画面は表示されません。起動時に小さな通知が出ます。

## 付録：自動セットアップがうまくいかない場合（手動インストール）

`install_all.bat` でエラーが出る場合は、以下の手順を試してください。

### Pythonのインストール
1. [Python公式サイト](https://www.python.org/downloads/windows/)からインストーラーをダウンロード。
2. インストール時、必ず **「Add Python to PATH」** にチェックを入れてください。
3. インストール後、パソコンを再起動してください。

### SumatraPDFのインストール
1. [公式サイト](https://www.sumatrapdfreader.org/download-free-pdf-viewer)から 64-bit installer をダウンロードしてインストールしてください。

### 足りないソフトの導入
1. `run_printer.bat` をダブルクリックして実行してください。自動的に必要な部品（watchdog）がインストールされます。

---

## 困ったときは
不具合がある場合は、以下のツールを使って状況を確認してください。
* **`check_status.bat`**: アプリが動いているか、エラーが出ていないか確認できます。
* **`stop_printer.bat`**: アプリを完全に停止させたいときに実行します。
* **`manual_test.bat`**: 自動検知を待たずに、特定のファイルを今すぐ印刷テストしたいときに使います。

## 🔒 セキュリティ・アンチウイルス対策について

WindowsやNortonなどのセキュリティソフトが「不明なプログラム」として警告を出す場合があります。その際は以下の設定を確認してください。

### 1. ファイルの「ブロック解除」
Windowsが「ダウンロードしたファイル」を保護して動かないようにしている場合があります。
1.  解凍したフォルダ内の各ファイル（`install_all.bat` や `run_printer.bat` など）を **「右クリック」** します。
2.  一番下の **「プロパティ」** を選びます。
3.  全般タブの下の方にある **「ブロックの解除」** にチェックを入れて **「OK」** を押します。

### 2. アンチウイルスソフト（Nortonなど）の警告について
Nortonなどが「リスクの高いプログラム」として検知した場合でも、本アプリは安全です。
*   **「詳細」** または **「許可する」** を選んで実行を継続してください。
*   もしファイルが勝手に削除されてしまった場合は、Nortonの「履歴」または「検疫」からファイルを **「復元」** し、そのファイルを **「スキャンから除外」** するように設定してください。

### 3. PCが固まったように見える場合
「このファイルを実行しますか？」という警告画面が、他のウィンドウの裏に隠れている可能性があります。
*   **Alt + Tab** キーを押して、隠れている確認画面がないか探してみてください。
*   どうしても動かない場合は、フォルダ内の **`emergency_stop.bat`** を実行してアプリを一旦停止させてください。
